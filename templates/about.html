📚 Curriculum Topics & Engineering Disciplines

Architectural implementation breakdown across all 5 core ML systems modules

Module 1

M1 — Machine Learning Lifecycle & Zero Training-Serving Skew

The system establishes a clean training-serving boundary. Preprocessing logic is never redefined in Flask. The fitted ColumnTransformer is serialized directly to artifacts/preprocessing.pkl and loaded during online serving to ensure zero statistical drift. 

Training Flow:   Raw CSV → Clean & Deduplicate → Feature Engineering → Preprocessor Fit → Model Fit → Artifacts
Serving Flow:    HTTP POST → Schema Validation → Feature Engineering → Preprocessor Transform → Inference → Response
Module 2

M2 — Supervised Learning & Regularized Linear Classification

Implements LogisticRegression equipped with class_weight='balanced' and L2 ridge penalty. Continuous metrics are standardized using StandardScaler to maintain convex optimization stability, while nominal features utilize OneHotEncoder(handle_unknown='ignore').

Module 3

M3 — Tree-Based Ensembles: Bagging vs. Boosting

Benchmarks non-linear orthogonal splits:

  • Decision Tree: Fast orthogonal tree with depth pruning (max_depth=6).
  • Random Forest: Bootstrap bagging ensemble of 120 decorrelated trees reducing sample variance.
  • Gradient Boosting: Stage-wise additive boosting minimizing multinomial cross-entropy log-loss.
Module 4

M4 — Feature Engineering & Physics-Informed Hazard Indices

Creates leak-free domain interaction features:

  • Speed_Delta & Speed_Ratio: Measures velocity relative to posted road limit.
  • Driver_Impairment_Risk: Interaction active if alcohol or unfastened seatbelts are observed.
  • Environmental_Hazard_Index: Additive score of poor lighting, adverse weather, and slippery pavement.
Module 5

M5 — Model Evaluation, Selection, and Imbalance Calibration

Because catastrophic fatal collisions represent a life-critical minority (~6%), accuracy is heavily skewed. The champion model is crowned via Macro F1, enforcing equitable error penalties across all severity classes. 

Evaluation Metrics Logged to artifacts/metadata.json:
- Stratified Holdout Split: 80% Train / 20% Test
- Macro F1 & Weighted F1
- Multiclass ROC-AUC (One-vs-Rest)
- Full Confusion Matrix across Minor, Moderate, Severe, Fatal
